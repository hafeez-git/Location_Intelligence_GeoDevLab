# GeoDev Lab Project — Kaduna Location Intelligence

## My Question

How can spatial data be used to understand the accessibility, environmental vulnerability, population context, healthcare availability, and settlement characteristics of locations in Kaduna Metropolis?

## What This Project Is About

This project explores how open geospatial data can be combined to provide location intelligence for Kaduna Metropolis.

A user will eventually be able to provide a coordinate or select an area on a map and receive spatial information about the selected location.

## The Data I Need

- **OpenStreetMap** — roads, amenities and water features
- **GRID3 Nigeria Health Facilities v3.0** — healthcare facilities
- **WorldPop Nigeria Population v3.0** — population estimates
- **Copernicus DEM** — elevation and terrain
- **CHIRPS v3** — rainfall
- **GRID3 Nigeria Settlement Extents v4.1** — settlement context

## Initial Analysis

The project will focus on:

1. Amenity proximity
2. Flood vulnerability
3. Road accessibility
4. Population density
5. Healthcare accessibility

Settlement extent/type will provide additional context for interpreting the results.

## Planned Output

The final product will be an interactive web-based Location Intelligence application for exploring locations within Kaduna Metropolis.

The project will evolve over time as I develop skills in GIS, spatial databases, PostGIS, backend development, APIs and Web GIS.
